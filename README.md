# Mphasis_Blackstone_LBO_Model
Constructed a leveraged buyout model on Mphasis Limited, replicating Blackstone's 2016 acquisition — modelled a theoretical 60/40 debt-equity structure across two tranches (₹4,375 crore total debt at 8.5-10.5%); derived MOIC of 4.0x and IRR of 31.7% at exit under multiple-neutral assumptions
